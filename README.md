# Ruang Digital v1.0 — Prototype Multi-Product Digital Store

## Cara menjalankan
1. Ekstrak ZIP ini.
2. Buka `index.html` menggunakan browser modern (Chrome, Edge, Firefox).
3. Tidak perlu instalasi atau server untuk demo dasar.

## Fitur versi 1.0
- Storefront responsif dan katalog multi-produk
- Pencarian dan filter kategori
- Keranjang sederhana dan checkout demo
- Kalkulator simulasi utang (lead magnet)
- Lead management (data disimpan di browser)
- Dashboard admin: overview, produk, pesanan, leads
- Tambah/hapus produk
- Verifikasi pesanan demo
- Ekspor CSV pesanan dan leads
- Digital Library prototype
- Data persisten melalui LocalStorage

## Catatan penting
Ini adalah prototype frontend. Checkout **tidak memproses pembayaran sungguhan**. Verifikasi pesanan pada admin adalah simulasi manual. Data LocalStorage hanya tersimpan di browser/perangkat yang sama dan bukan database server. Jangan gunakan untuk menyimpan data pelanggan nyata atau sensitif.

## Pengembangan selanjutnya
Versi 2.0 sebaiknya menambahkan backend/API, database, autentikasi admin yang aman, dan penyimpanan file digital. Setelah itu integrasikan payment gateway resmi dan webhook pembayaran.
